# Регрессии Sirus

Регрессии проверяются штатной командой `python scripts/run_tests.py` вместе с остальными тестами (Lua 5.1 через lupa).

Покрытие: каналы «Мир», «Мир(А)», «Мир(О)», актуальные ID и языки независимо от фракции; пары и тройки GetChannelList; строго булева настройка ограничения, применение без перезагрузки, независимый настоящий Chat-lock и отсутствие автоматической отправки очереди; первое открытие истории, поздняя ширина, скрытые сообщения, переносы, сохранение позиции чтения и размер эмодзи.

`ui_rig.lua` расширяет FakeUI детерминированным измерением текста, но не воспроизводит реальную геометрию WoW. Тесты не заменяют проверку в Sirus: первое открытие после /reload, ресайз, ссылки и эмодзи, отправка в мировые каналы каждой фракции и переключение запрета внутри активности. Признак М+ и форма API должны быть подтверждены в игре.

Русское приглашение, ссылка на форум и лимит 255 байт проверяются в `tests/core/test_invite_handler.lua`.
